## 🔥 About The Project

**MotoRank Elite** is a passion-driven web platform built by riders, for riders. Every ranking is based on real-world riding experience, expert analysis, and community feedback — making it the most honest, data-driven supersport motorcycle ranking site on the internet.

> *"Founded by passionate track-day riders with decades of combined experience on 600cc and 1000cc machines."*

| 🏍️ Bikes Ranked | 💬 Rider Reviews | 🏷️ Brands Covered |
|:---:|:---:|:---:|
| **14+** | **2,400+** | **6** |

---

## ✨ Features

- 🏆 **Bike Rankings** — Ranked by rider experience score across ALL, 600cc, and 1000cc classes
- ⚖️ **Head-to-Head Compare** — Side-by-side spec comparison with an overall winner verdict
- 📋 **Detailed Bike Pages** — Full specs, appearance gallery, and performance radar chart
- 📊 **Performance Radar** — Visual radar chart scoring Power, Handling, Sound, Comfort & Value
- ⭐ **Rider Reviews** — Community reviews with rider level badges (Beginner / Intermediate / Expert)
- 📝 **Riding Tips & Blog** — Articles and guides for supersport riders
- 🔐 **User Accounts** — Register & login to submit reviews

---

## 🛠️ Built With

- **HTML5** — Single-file structure with semantic markup
- **CSS3** — All styles written inline in `<style>` tags
- **Vanilla JavaScript** — All logic written inline in `<script>` tags
- **No frameworks. No dependencies. Just the web.** ⚡
